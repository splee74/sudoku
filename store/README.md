## 등록 순서

### 1단계 : 게임을 인터넷에 올리기 (GitHub Pages)

플레이스토어 앱은 인터넷에 올린 게임 주소를 앱으로 감싸는 방식(TWA)으로 만듭니다.

1. GitHub 저장소 `splee74/sudoku` → **Settings → Pages**
2. Source : **Deploy from a branch**, Branch : **main / (root)** → Save
3. 몇 분 뒤 `https://splee74.github.io/sudoku/` 에서 게임이 열리면 성공

> 폴더의 `.nojekyll` 파일은 지우지 마세요. 4단계의 `.well-known` 폴더가 인터넷에 올라가려면 필요합니다.

### 2단계 : 앱 파일 만들기 (PWABuilder)

1. https://www.pwabuilder.com 에 게임 주소 `https://splee74.github.io/sudoku/` 를 넣고 Start
2. **Package for stores → Android → Generate Package**
   - Package ID : `io.github.splee74.sudoku` 처럼 정하면 됩니다 (한 번 올리면 못 바꿈)
   - App name : 스도쿠 승급전 / Launcher name : 스도쿠
3. 받은 zip 안의 파일
   - `*.aab` : 플레이스토어에 올리는 앱 파일
   - `signing.keystore`, `signing-key-info.txt` : **앱 서명 열쇠. 잃어버리면 앱을 고쳐 올릴 수 없습니다.** 안전한 곳에 꼭 따로 보관하세요 (GitHub에는 올리지 마세요)
   - `assetlinks.json` : 4단계에 씁니다

### 3단계 : 주소창 없애기 (assetlinks.json)

이 파일이 제자리에 없으면 앱 맨 위에 인터넷 주소창이 보입니다.

**주의 :** 이 파일은 사이트의 **맨 앞 주소**에 있어야 합니다.
`https://splee74.github.io/.well-known/assetlinks.json` (O)
`https://splee74.github.io/sudoku/.well-known/assetlinks.json` (X, 안드로이드가 보지 않음)

그래서 GitHub에 **`splee74.github.io`** 라는 이름의 저장소를 하나 더 만들고, 그 안에 `.well-known/assetlinks.json` 과 빈 `.nojekyll` 파일만 넣어 Pages를 켜면 됩니다.
(나중에 자기 도메인을 사면 이 과정이 더 간단해집니다)

플레이스토어에 처음 올린 뒤 Play Console의 **설정 → 앱 서명** 에 나오는 "SHA-256 인증서 지문"도 `assetlinks.json` 의 `sha256_cert_fingerprints` 목록에 **함께** 넣어야 합니다. (구글이 앱에 다시 서명하기 때문)

### 4단계 : Play Console 에 올리기

1. https://play.google.com/console 개발자 계정 만들기 (한 번 25달러)
2. **앱 만들기** → 앱 이름 "스도쿠 승급전", 게임, 무료
3. 아래 "스토어 글", "앱 콘텐츠 답변" 대로 채우기
4. **개인 개발자 계정이면** 바로 공개할 수 없고, 먼저 **비공개 테스트**를 해야 합니다.
   테스터 **12명 이상**이 **14일 동안** 앱을 깔아 두어야 공개(프로덕션) 신청이 열립니다.
   가족·친구에게 부탁해 두면 좋습니다. (구글 정책은 바뀔 수 있으니 Play Console 안내를 확인하세요)

## 스토어 글

**앱 이름** (30자 이내)
```
스도쿠 승급전
```

**간단한 설명** (80자 이내)
```
하수에서 신까지! 4×4부터 9×9까지 한 단계씩 올라가는 스도쿠. 오늘의 퍼즐, 배지 모으기
```

**자세한 설명** (4000자 이내)
```
하수에서 시작해 한 단계씩 올라가는 스도쿠, 스도쿠 승급전입니다.

■ 처음이어도 괜찮아요
작은 4×4 판에서 직접 눌러 보며 규칙을 익히는 따라 하기가 있어요. 계산은 전혀 필요 없고, 어느 칸에 어떤 숫자가 들어갈지 차근차근 따져 보는 놀이예요.

■ 10단계 승급전
하수 → 평민 → 중수 → 고수 → 영웅 → 지존 → 초인 → 패왕 → 대왕 → 신
같은 등급에서 5판을 깨면 승급! 4×4, 6×6을 거쳐 9×9 판까지 점점 어려워져요. 원하는 등급을 골라서 할 수도 있어요.

■ 오늘의 퍼즐
매일 새로운 9×9 퍼즐이 하나씩 나와요. 같은 날에는 모두 같은 퍼즐이라 가족, 친구와 점수와 시간을 견주어 보세요. 하루도 빠지지 않고 풀면 연속 기록이 쌓여요.

■ 배지와 통계
첫걸음, 무결점, 5연승, 번개손, 일주일 개근… 19가지 배지를 모아 보세요. 성공률, 최다 연승, 평균 시간도 한눈에 볼 수 있어요.

■ 편하게 즐기는 기능
· 메모, 힌트, 되돌리기, 지우개
· 같은 숫자 · 같은 줄 강조 표시
· 다크 모드 (휴대폰 설정 따라가기)
· 파스텔, 나무판, 알록달록 등 10가지 판 꾸미기
· 큰 글씨와 큰 단추
· 인터넷 없이도 할 수 있어요
· 하던 판은 자동으로 저장돼요

■ 개인정보를 모으지 않아요
회원 가입도, 광고도 없어요. 모든 기록은 휴대폰 안에만 저장됩니다.
```

**카테고리** : 게임 → 퍼즐
**태그** (고를 수 있으면) : 스도쿠, 숫자 퍼즐, 두뇌 게임
