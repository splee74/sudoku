개인정보처리방침

스도쿠 승급전 · 2026년 11월 23일부터 적용 (랭킹 추가)

한 줄 요약 : 로그인하지 않으면 개인정보를 전혀 모으지 않습니다. 로그인을 고르신 경우에만 기록을 지켜 드리기 위해 이름과 게임 기록을 계정에 저장하며, 앱 안에서 언제든 지울 수 있습니다. 랭킹에는 직접 정한 닉네임과 점수만 보이고, 실제 이름 · 사진 · 이메일은 보이지 않습니다.

1. 로그인하지 않을 때

개인정보를 모으지 않습니다. 게임을 이어서 할 수 있도록 아래 내용을 사용하시는 기기 안에만 저장하며, 이 내용은 기기 밖으로 나가지 않습니다.

  • 내 등급, 점수, 걸린 시간, 받은 배지 같은 게임 기록
  • 하다가 멈춘 판
  • 효과음, 화면 밝기, 스킨 같은 설정

게임 안의 "내 기록 → 기록 지우기"를 누르거나, 앱을 지우거나, 휴대폰 설정에서 앱 데이터를 지우면 모두 사라집니다.

2. Google로 로그인할 때

로그인은 고르실 수 있는 기능이며, 휴대폰을 바꾸거나 앱을 다시 깔아도 기록이 이어지게 하려는 목적으로만 씁니다.

  • 받는 정보 : 로그인한 계정의 이름, 프로필 사진 주소, 이메일 주소, 계정을 구분하는 번호
  • 저장하는 게임 기록 : 등급, 점수, 걸린 시간, 받은 배지, 통계
  • 쓰는 곳 : 화면에 이름과 사진을 보여 주고, 기록을 계정에 저장하고 불러오는 데만 씁니다. 광고나 다른 목적에 쓰지 않으며, 다른 사람에게 보이지 않습니다. (랭킹에 보이는 것은 아래 3번)
  • 보관하는 곳 : 구글의 Firebase(Google LLC, 미국 등 구글 데이터 센터)에 보관됩니다. 로그인할 때 인터넷을 통해 옮겨지며, 전송은 암호화됩니다.
  • 보관 기간 : 계정을 지울 때까지 보관하고, 지우면 바로 없어집니다.

3. 랭킹

로그인한 뒤 닉네임을 정한 경우에만 랭킹에 오릅니다. 닉네임을 정하지 않으면 랭킹에 아무것도 올라가지 않습니다.

  • 다른 사람에게 보이는 것 : 직접 정한 닉네임, 등급, 랭킹 점수(그 주 · 그 달에 모은 점수, 오늘의 퍼즐을 푼 시간), 받은 왕냥이 표시(👑), 가장 높은 등급에 오른 날짜
  • 보이지 않는 것 : 구글 계정의 실제 이름, 프로필 사진, 이메일 주소
  • 보관하는 곳과 기간 : 위와 같은 Firebase 에 보관합니다. 지난 달 1~3위와 가장 높은 등급에 처음 오른 사람은 "명예의 전당"에 계속 남습니다.
  • 지우기 : "계정과 저장된 기록 지우기"를 누르면 닉네임, 이번 주 · 이번 달 · 오늘 랭킹 기록, 명예의 전당 이름이 함께 지워집니다.

4. 계정과 기록 지우기

앱의 "내 기록" 화면 → "계정과 저장된 기록 지우기"를 누르면 계정에 저장된 기록과 로그인 정보가 바로 지워집니다. 앱을 쓸 수 없는 경우에는 아래 문의 게시판에 지워 달라고 남겨 주시면 처리해 드립니다.

로그아웃만 하면 계정의 기록은 남아 있다가, 다시 로그인하면 이어집니다.

5. 다른 곳에 주는 정보

없습니다. 광고, 이용 통계 분석, 위치 확인 기능이 없으며, 위의 로그인·저장(Firebase) 말고는 다른 회사에 정보를 주지 않습니다.

6. 휴대폰 기능 사용

  • 진동 : 틀린 숫자를 넣었을 때 짧게 떨립니다. 설정에서 끌 수 있습니다.
  • 인터넷 : 게임 파일을 받고, 로그인한 경우 기록을 저장하고 랭킹을 보는 데 씁니다. 한 번 연 뒤에는 인터넷 없이도 게임을 할 수 있습니다.

7. 어린이

로그인하지 않으면 개인정보를 모으지 않습니다. 만 14세 미만 어린이는 보호자의 동의 없이 로그인하지 말아 주세요.

8. 바뀌는 경우

광고처럼 정보를 다루는 기능을 더 넣게 되면, 넣기 전에 이 글을 먼저 고쳐 알려 드립니다.

9. 문의

궁금한 점이나 기록 삭제 요청은 문의 게시판에 남겨 주세요.
